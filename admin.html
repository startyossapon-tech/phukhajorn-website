GitHub Repository

ต้องมีสิทธิ์: Contents (read & write)

lock เปลี่ยนรหัสผ่าน

help วิธีใช้งาน

  1. สร้าง GitHub Personal Access Token ที่ github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. ตั้งค่า Repository permissions: Contents = Read and write
  3. กรอก Username, Repo, Branch (main), Token แล้วกด "บันทึก"
  4. กด "ทดสอบ" เพื่อยืนยันการเชื่อมต่อ
  5. กลับหน้าสต็อก กด + เพิ่มรถ อัพโหลดรูป กรอกข้อมูล กด "บันทึกและอัพโหลด"
  6. รถจะขึ้นบนเว็บหลักทันที (อาจรอ GitHub Actions 1-2 นาที)
